# v1 build

Started 2026-10-10. Status: not started; no code yet.

Builds the [v1 scope](../../decisions/2026-10-10-v1-scope.md) on the [rendering stack](../../decisions/2026-10-10-rendering-stack.md). Estimates are agent working time.

## Phase 1: core viewer (about 4 h)

Window and fullscreen, wgpu quad with mipmaps, fit, zoom, pan, screen rotation, opening by every route, folder filter, image list with sort modes and grouping, preload cache, navigation under the advance limit, slideshow.

Done when:

- A folder of 50 MP JPEGs pages forward with no visible wait once the preload cache is warm.
- Holding Space advances once per advance limit, never faster.
- An image minified to a quarter of its size shows no moiré or shimmer while panning.
- Every key in the scope decision's *Opening*, *Navigation*, *Viewing* and *Ordering* lines works, except I (phase 3).

## Phase 2: file actions (about 1 h)

Delete to the Recycle Bin, move, copy, Ctrl+C, Ctrl+V.

Done when a deleted image is restorable from the Recycle Bin, the image list advances past deleted and moved images, and a clipboard image pasted with Ctrl+V displays.

## Phase 3: polish (about 1 h)

Info overlay, preferences screen and file, session restore.

Done when a restart reopens the same image list, current image, sort mode, shuffle order and window placement on the same monitor.
