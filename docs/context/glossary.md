# Glossary

The project's ubiquitous language, one row per concept; the index's *Language* section says how to use it. Sorted by term.

| Term | Meaning | Avoid | In code |
| --- | --- | --- | --- |
| Advance limit | The shortest interval between image changes while Space or Backspace is held; default 500 ms. | fast-forward, fast-back | |
| Current image | The image on screen, one position in the image list. | current slide | |
| Fit | The zoom level at which the whole image fits the window; every image opens at fit. | | |
| Folder filter | Folder names excluded when opening a folder; default `private`. | family filter, excluded folders | |
| Group by subfolder | Ordering that keeps each subfolder's images together, sorted by the sort mode within each group; Ctrl+Left/Right jumps between groups. | | |
| Image | A JPG, PNG, TGA or BMP file the viewer can show. | photo, slide, picture | |
| Image list | The ordered images from the last open, after the folder filter, sort mode and grouping are applied. | playlist | |
| Info overlay | Text drawn over the image; I cycles it through none, filename only and full details. | | |
| Pan | Moving a zoomed image within the window by drag or arrow keys. | scroll | |
| Preferences | The owner's persisted options, and the screen opened with P that edits them. | settings, config, options | `Preferences` |
| Preload cache | Decoded images around the current image, held under a memory budget so navigation shows them without waiting. | | |
| Recursive open | Opening a folder together with all its subfolders (Shift+O); sets the sort mode to shuffle. | | |
| Screen rotation | Turning how the current image is drawn by 90°. Never written to the file; lasts until the app closes. | lossless rotation, EXIF rotation | |
| Session restore | On startup, reopening the last image list, current image, sort mode, shuffle order and window placement. | | |
| Shuffle | The sort mode that gives the image list a random order, kept until the next shuffle. | random | |
| Slideshow | Timed automatic advance to the next image, toggled with A. | | |
| Sort mode | The image list's order: name (N), date (D), size (Z) or shuffle (S); V reverses it. | | |
| Zoom | Scaling the image relative to fit, by right-drag, + / - or Ctrl+ / Ctrl- (double or half). | | |
